05结算规则

  • 评选时间：每个自然周（周一至周日）统计评选，下周一公布评选结果。
  • 评选范围：仅激励 30 日内发布的作品；同一作品只能选一个平台提报，每个作品仅可获得 1 次激励。
  • 多平台不叠加：同一作品发了多个平台，只取数据最高的一个平台计奖。
  • 奖项叠加：话题投稿奖（发就有）+ 爆款奖（按最高播放档）可同时拿；爆款奖只按命中的最高一档，不跨档叠加，系数 5.0 只作用于爆款奖。
  • 播放量口径：以上传截止时各平台后台的真实播放数为准，官方逐条复核。

06常见问题

怎样才算“合规发布”、能计入奖励？

需同时满足：① 作品是 noknoc 站内已发布内容；② 站外发布带齐官方话题；③ 真实公开账号；④ 在活动期内发布。缺任一项不计入。

草稿 / 没发布的作品算吗？

不算。作品必须站内已发布、且站外正式公开发布并带齐话题。

怎么提交？什么时候发奖？

把作品链接 + 数据截图填进提报问卷；每周运营统一复核，以当期公告为准。

01我们在找什么样的人

一句话：能搭世界、会讲故事、愿意带着一群人一起玩的人。你不需要是专业策划或职业 DM，但我们希望你：

  • 能搭建世界观、设计玩法——有自己想做的题材，能把“一个好点子”变成“一群人能玩起来的规则”。
  • 会用 AI Agent 做视频——noknoc 的剧情靠生成视频推进，你需要熟练使用 AI 生视频。
  • 有基础的社群运营能力——能发群公告、答疑解惑、维持群内讨论氛围。
  • 有一定的招募能力——能从自己的圈子（粉丝群、语C群、同好群、社交平台）拉到初始玩家。

最核心的一条
以上都不是最重要的——最最最核心的是：你真的想建一个属于自己的世界。

02成为世界主后，你要做什么

  • 开企前：选定题材 → 搭建世界观 → 设计主线玩法与奖励 → 招募玩家。我们提供模板和必要的协助，无需从 0 开始。
  • 开企后：按周推进剧情。最小企划时长单位为 1 周，建议企划时长 2~3 周。
节奏你要做的事

D4–D6发布事件、下发线索，玩家创作后续剧情

核心交付物
每轮 D7 产出一份归档（本轮既定事实 · 本轮结算），这是企划的核心交付物，也是下一轮剧情的地基。收官时完成结算（成就 / 奖励发放）与整期归档。

03企划世界怎么设计

这是我们跑通「魔法学院企划」后沉淀的企划模版，照着做，你的世界大概率能玩起来。想看范例，noknoc 内搜索【我的魔法学院】。

  • 两条核心判断标准：① 鼓励不同角色加入，且有共同的画风和属性（企划世界是 2D/3D 画风，真人 / 毛毡 / 像素风格 OC 就不适配）；② 有主线剧情，核心大事件围绕所有参与者展开，且能拆分出不同小事件——每个玩家都是自己剧情的主角、独立成线，但所有人收束在同一个有限范围内。
  • 世界观三项底线：玩家大致主线（用户进来之后要做什么）、世界共创规则（明确“在这个世界里不能做什么”）、结局方向（玩家角色的最终状态方向 + 剧情结果）。
  • 主线要简洁易懂——保证 90% 的玩家都能理解并完成。
  • 小事件三条要求：必须是简单的情景 / 突发事件，不过于复杂，不增加玩家写反应剧情的成本；不建议让玩家站队做非黑即白的选择；不能过度干扰主线的推进。
  • 阵营 / 身份体系（非必选，但鼓励设计）：建议 3–5 个（两个易成二元对立，六个以上难维护）；不同阵营在技能 / 喜好 / 属性 / 专属线索上有差异；相互制约又有合作；不做非黑即白；注意人数平衡，别让某一派超过半数。参考：魔法学院的四学院制、修仙世界的宗门与散修、DND 的阵营体系。
  • 题材建议：最推荐西幻（公会 / 冒险者 / 精灵矮人——种族职业现成，公会发任务顺理成章，语C 和绘圈受众多）与修仙宗门（功法丹药阵法现成，外门弟子入门＝新生入学，宗门大比＝比赛，且无版权问题）；推荐现代异能（管理局 / 事务所，受众多但能力体系要自己编）。原创或泛化设定优先；想做知名 IP 二创请先与我们沟通评估版权风险。
